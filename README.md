# Natnael Tilahun Sinshaw Portfolio

Personal academic portfolio website focused on Data Science, Machine Learning, and Computer Vision.

## Focus Areas

- Data Science
- Machine Learning
- Computer Vision
- Deep Learning
- Statistical Modeling
- Applied AI research

## Project Structure

- index.html: Main website content, metadata, and structured data
- style.css: Visual design, layout, typography, and responsive styles
- script.js: Interactive behavior and dynamic updates
- publications.json: Publication records rendered in the Publications section
- llms.txt: LLM-readable profile summary for AI discovery
- sitemap.xml: Search engine sitemap
- robots.txt: Crawler directives and sitemap location
- assets/: Images and documents

## Local Development

1. Open this folder in VS Code.
2. Run with any static server, for example:
   - python3 -m http.server 8000
3. Open http://localhost:8000 in your browser.

## SEO and Discoverability

This site includes:

- Title and meta description
- Open Graph and Twitter card metadata
- Canonical URL
- Structured data (Person, ProfilePage, ItemList)
- sitemap.xml
- robots.txt
- llms.txt

## Content Update Checklist

When making major updates:

1. Update page content in index.html.
2. Keep publication data current in publications.json.
3. Update llms.txt summary if your focus changes.
4. Refresh lastmod in sitemap.xml for key URLs.
5. Verify robots.txt still points to the correct sitemap.
