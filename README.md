# Data Science Portfolio

This repository contains a simple portfolio template designed for a data science or machine learning role. The site can be hosted with GitHub Pages and customized with your own information.

## Usage

1. Update `index.html` with your name, biography, profile photo, and project details.
2. Customize the Education, Experience, Publications and Awards sections with your accomplishments.
3. Add your preferred links for LinkedIn and ORCID (or other networks) in the contact area.
4. Commit your changes and enable GitHub Pages in your repository settings.
5. Your portfolio will be available at `https://<username>.github.io`.

Feel free to modify the styles or structure to match your preferences.
