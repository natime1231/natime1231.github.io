Multimodal RAG Chatbot

The Challenge

Standard RAG systems struggle with technical documents containing charts and diagrams. The goal was to build a system that could retrieve and reason across both text and images with high faithfulness.

My Approach

I implemented a multimodal retrieval pipeline using ColPali for document embedding and GPT-4o for synthesis. I added a verification layer that cross-references generated answers with retrieved context to reduce hallucinations.

Tech Stack

FastAPI LangChain PostgreSQL / pgvector Docker

Key Results

  • Achieved 92% faithfulness score on a custom technical evaluation set.
  • Reduced hallucination rate by 15% using the verification layer.
  • Deployed as a containerized microservice with < 200ms latency for text queries.

Auditing Gender Classification Bias

The Challenge

Gender classification models often exhibit significant performance disparities across intersectional subgroups (e.g., darker-skinned women), leading to allocative and representational harms.

My Approach

I designed a data-centric auditing pipeline. First, I used clustering to identify underrepresented subgroups in the training data. Then, I applied adversarial debiasing and equalized odds regularization during training to mitigate learned biases.

Tech Stack

PyTorch FairLearn Scikit-learn Pandas

Key Results

  • Reduced False Positive Rate disparity by 40% across intersectional groups.
  • Maintained 95% overall accuracy while satisfying equalized odds constraints.
  • Published findings in a preprint on data-centric fairness auditing.
