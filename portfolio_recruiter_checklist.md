# Portfolio Recruiter Checklist and Gap Analysis

Date: April 2, 2026
Website reviewed: natnaelsinshaw.github.io

## Goal
Capture the top recruiter-focused improvements for this data science portfolio and keep them as a reusable reference.

## Current Snapshot
- Strengths:
  - Clear profile, education, publications, awards, and contact section.
  - Relevant data science and ML skill coverage.
- Major visibility issue:
  - The Projects section is commented out in `index.html`, so practical work is not visible to recruiters.

## Top 3 Missing Items Recruiters Usually Look For

### 1) Visible, high-quality project section
Why it matters:
- Recruiters prioritize concrete project evidence over skill lists.
- Strong portfolios make best projects immediately visible.

Current gap:
- Projects content exists but is hidden (commented out), so reviewers cannot evaluate implementation depth.

Recommendation:
- Surface 3 strongest projects on the main page.
- Keep each project concise and scannable.

### 2) Quantified impact and business framing per project
Why it matters:
- Recruiters look for problem-solving with measurable outcomes, not just tools used.
- Good project summaries answer: problem, approach, impact.

Current gap:
- Limited visible business/result metrics on the page.

Recommendation:
- For each project include:
  - Problem: What decision or outcome needed improvement.
  - Approach: Data source, method/model, and evaluation setup.
  - Impact: At least 1-2 measurable outcomes (for example, F1/AUC lift, error reduction, processing time reduction, fairness metric change).

### 3) Direct proof links for each project
Why it matters:
- Recruiters skim quickly and need immediate proof of execution.
- Best portfolios provide code + explanation + optional demo.

Current gap:
- Hidden project cards mean no visible direct proof path from the home page.

Recommendation:
- Add visible links per project:
  - GitHub repository
  - Readme or case-study write-up
  - Optional demo/dashboard
  - Dataset source and reproducibility note

## Suggested Recruiter-Friendly Card Template
Use this structure for each project card:

- Project title
- One-line business or research objective
- Problem
- Approach
- Impact (with numbers)
- Links: Code | Report | Demo (optional)
- Stack tags
